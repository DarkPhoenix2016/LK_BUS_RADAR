# Real-time Sync Server

## Environment variables

- `MONGODB_URI` (required)
- `PORT` (default `4000`)
- `API_TIMEOUT_MS` (default `10000`)
- `API_RETRY_COUNT` (default `3`)
- `API_RETRY_DELAY_MS` (default `500`)
- `MONGO_MAX_POOL_SIZE` (default `20`)
- `MONGO_MIN_POOL_SIZE` (default `5`)

## Run

```bash
npm install
npm run dev
```
